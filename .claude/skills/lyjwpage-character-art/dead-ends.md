# 试过不行的路线

提新做法前先对一遍。条件变了（换了角色、换了工具版本）可以重试，提的时候说清楚哪里不一样。

| 路线 | 结论 | 为什么 |
| --- | --- | --- |
| 立绘矢量化成 SVG（vtracer） | 弃 | 试了 8 组参数，误差约是 WebP 的 2 倍；眼睛高光并成平涂色块，线稿质感没了。最好的一组 gzip 后约 790 KB、近 6000 条路径，重绘约 16 ms；WebP 约 90 KB、1.9 ms。 |
| 发光线稿（法阵、符文）描成 SVG | 弃，改超分 | 光晕糊成一团，细符文丢失。 |
| isnet-anime 抠图 | 弃，改 BiRefNet | 把背景大字和地面碎片一起抠进来。 |
| 阈值抠图 | 弃，改反解 | 发丝缝透出底色，断成虚线。 |
| 程序画眼皮做闭眼 | 弃，改 Codex | 画出来很假。 |
| 交叉淡化做眨眼 | 弃，改眼皮扫向闭眼格 | 睁闭两张叠在一起有重影。 |
| LaMa 补被挡住的头发 | 弃，改 Codex | 头后面补成一团暗色糊块；补额头时把发丝往下延续。 |
| 拆成 6 层做整体动态 | 只留闭眼帧 | 刘海相对脸一动，耳朵、下颌、鬓角一圈全是皮肤对皮肤的接缝；动态继续用位移场。 |
| 整条手臂当硬板绕肩转 | 弃，只拆手 | 前臂在胸前滑动，肩带和补全图错位，lyjw：「直接都分离了」。 |
| 手臂环周围加同心水波圈 | 删 | lyjw：「波动不是这样加的，有点点扭曲就行」。 |
| Antigravity（经 t3code）做法阵与光炮 | 弃 | lyjw：「效果不好」。 |
| mesh-avatar-studio 一键做 avatar | 不接 | 见 `docs/references.md` 的 Mesh Avatar Studio 条目。 |
