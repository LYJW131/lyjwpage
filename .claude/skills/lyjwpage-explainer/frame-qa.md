## 你在看什么

一部 2D 讲解动画（站点 lyjw.me 的运行原理），每帧 960×540。派单提示词会写明这一批是中文版（24 帧每秒，逐帧）还是英文版（每秒抽 6 帧）。几帧拼成一张图：每格上方一条白底黑字的标签写着「帧号 章号 小节」，例如 `04053 ch03 11.00`（第 03 章第 11 小节）；同一张图里的格子按从左到右、从上到下的顺序，是**连续的帧**。中文版相邻两帧只差 1/24 秒，应该几乎一模一样，只有平滑的运动；英文版相邻两格差 1/6 秒，大体相同，动画在走。标签里的章号变了，就是换章：换章处画面硬切、整个换掉是正常的；同一章里镜头甩过去时也会一两帧整体模糊、换场。

比较两格里同一个元素的位置时，按各格自己的画面坐标比：格子之间隔着标签和空隙，不要把两格之间的距离当成元素移动了。

画风：
- 暗底章：近黑底、细网格、骨白线条、橙色点缀；纸面章：米白纸、网格、墨色线条、橙色点缀。整片有颗粒、暗角和一点辉光，这些都正常。
- 旁白在左下，两行大字，**逐字亮起**：还没轮到的字是暗灰色，这是正常的；列表里还没轮到的行也可能是暗的。
- 卡片、标签会淡入淡出；镜头会平移、推拉，平移时有运动模糊。
- 一只橙色像素小螃蟹 Clawd 是吉祥物，会到处跳，有时戴道具；它不挡字时是正常的。
- 每章收尾会拉远看整张「图版」（PLATE），这时字很小、看不清是正常的，只报明显的压字、错位。
- 中文版：代码标识符、端点、提交短哈希（如 `f6ef255`）、Worker 名字本来就是英文等宽字，不算问题。
- 英文版：画面上的字都应是英文，还留着中文的标签、旁白、卡片字算 `garbled`（漏翻）。歌名、剧名、人名、提交说明、PR 标题这类数据本来就是原文（日文、中文都有），不算。英文比中文长，特别留意越出框线、压到别的字、被截断。

## 要找的问题（按类型）

- `overlap`：字压着字、字压在线或图形上，读不清。
- `overflow`：字或卡片越出自己的框、表格列或卡片边线。
- `clipped`：字、卡片被画面边缘截掉（明显是正在进出画面的运动除外）。
- `garbled`：乱码或不该出现的字：方框「□」、`undefined`、`NaN`、`null`、`ch08.n4a` 这类原始键名、重复的标签、该是中文的标签变成别的内容、英文单词拼错（字母颠倒、多字、少字）。
- `covered`：吉祥物或别的元素挡住了字。
- `stray`：不属于这里的东西：位置古怪的印章、标签、小点、图形残留，同一个标签旁边多出一个淡淡的重影。
- `misaligned`：本该对齐的一列或一排里有一个偏出去，边框断开缺一截，元素和它的框对不上。
- `glitch`：只在一两帧出现的毛病：整帧变黑或变空、闪进别的场景、颜色反转或偏色、某个元素跳到别处又跳回来、字突然消失一帧。看相邻格子对比最容易发现。
- `other`：其他明显坏掉的地方。

不要报：逐字亮起、淡入淡出、颗粒、暗角、辉光、运动模糊、装饰线的正常交叠。拿不准的也报，但把 `confidence` 写成 `low`。

## 怎么看

1. 按文件名顺序把派单里列出的**每一张**图都用 Read 打开看完，一张不跳。每轮可以同时 Read 最多 4 张。
2. 每张图里每一格都看，相邻格互相对比；一张图里有问题也要继续看完别的格。
3. 同一个问题连着出现在多帧里，只记一条，写上你看到它的第一帧和最后一帧编号。
4. 每看完 8 张图，就把到目前为止的结果写进报告文件（覆盖写），免得中途丢失。

## 报告

报告文件写成一个 JSON 对象：

```json
{"sheets_total": <图的张数>, "sheets_reviewed": <你实际打开看过的张数>,
 "findings": [{"first": "04059", "last": "04076", "type": "overlap", "confidence": "high", "where": "在画面哪里", "what": "看到了什么"}]}
```

`first`、`last` 只写格子标签开头的 5 位帧号（如 `04053`）；只出现一帧的，两项写同一个帧号。`where`、`what` 用中文，各一句。

最后一条消息只回一行：「看了 X/Y 张，记了 Z 条」，不要别的话；结果以报告文件为准。
