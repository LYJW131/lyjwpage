# 别处播放推断精度实测

> 类型：record。按 771b842 2026-10-03 核对，快照不维护，不当现状引用。

核验时间：2026-10-03 07:53–08:57，UTC+8。结论：Apple「最近播放的歌」在一首歌**开播时**就把它排到最前，抖动不超过 5 秒轮询的分辨率；按时长把连续播放对齐后，每分钟拉一轮时 97% 的听歌时间标对了歌名，开播误差中位 8 秒。线上 `771b842` 的画法在同一段播放上只标对 13%，整条错一首。

## 怎么测的

- 播放端：一台 iPhone 连续放一个歌单，没有手动切歌；Mac 整段停在暂停，不提供在放的实测，量到的是别处播放这一路自己的精度。
- 基准：本机每 5 秒拉一次 `/v1/me/recent/played/tracks`（与采集 Worker 同一份 user token，`limit=10`），两段共 56 分钟，中间停拉约 8 分钟。列表最前那首换了就记一次开播，取前后两轮的中点（误差 ±2.5 秒），放到下一首开播或时长用完；停拉那段只知道中间放过，不计分。
- 生产窗口：同一时段生产采集 Worker（每分钟一轮）记下的 `(since, t]`，从 D1 `listening_plays` 只读取出。
- 数据：`src/lib/testing/recent-tracks-session.json`，Apple 条目 id 换成了 `t01`…，曲名、艺人、时长照原样。回放与打分在 `src/lib/testing/listening-replay.ts`。
- 口径：标对 = 可计分的播放时间里被同名段覆盖的比例；开播误差 = 同名、开播最近的那一段减基准开播。按某个间隔回放时，每 N 轮取一轮，起点分别取 0…N−1，各相位合并统计。

## 上榜时机

相邻两首上榜的间隔减去**前一首**的时长，按播放顺序是 -2.5、0.9、2.4、-1.8、0.2、2.4、-0.5、16.7、2.0、-2.4、-2.3、1.1 秒。除一次 16.7 秒（播放端停了一下）外都在 ±2.5 秒内，就是 5 秒轮询的分辨率。

如果播完才上榜，间隔应等于后一首的时长。D1 里 10-03 06:24–07:15 手机交替循环 NeverFiction（124 秒）与 GHOST（283 秒）：NeverFiction→GHOST 约 2 分钟、GHOST→NeverFiction 约 5 分钟，只有「开播即上榜」对得上。

## 结果

| 口径 | 标对歌名 | 开播误差 中位 / p90 |
| --- | ---: | ---: |
| 旧画法，每分钟一轮（线上节奏） | 13% | 203 秒 / 253 秒（错一首） |
| 新算法，每 15 秒一轮 | 99% | 2 秒 / 6 秒 |
| 新算法，每 30 秒一轮 | 98% | 4 秒 / 12 秒 |
| 新算法，每分钟一轮 | 97% | 8 秒 / 14 秒 |
| 新算法，每 5 分钟一轮（闲档） | 94% | 12 秒 / 31 秒 |
| 新算法，用生产实际记下的窗口 | 97% | 4 秒 / 21 秒 |

- 旧画法的数字是 `771b842` 的 `listeningTrace` 与 `stateLaneView` 在同一份数据上的回放。线上 lyjw.me 当时画出的别处播放，07:55–08:29 只有 15% 的时间标对；GHOST 整首没画，因为暂停在 GHOST 上的 Mac 被当成了解释。
- 生产窗口比实际拿到列表晚 8–12 秒（窗口用的是状态核心收到提交的时刻，采集 Worker 先交专辑列表）；新算法用的窗口是同一批，没有扣掉这段偏移。
- p90 主要来自那次 16.7 秒的停顿：每分钟一轮的窗口分辨不出这么短的停顿，停顿后的几首仍按停顿前的节奏推，早了约 20 秒，直到后面某一轮的窗口对不上才重新对齐（生产窗口那一行是 3 首）。

## 没测到的

- 从按下播放到上榜的固定延迟：请播放端在 08:15、08:20、08:30 整点切歌做标定，三次都没有切歌。基准与推断都以上榜时刻为准，这个延迟只让整段一起平移；抖动只有几秒，说明不是攒批上报。
- 暂停、拖进度、单曲循环不在列表里留痕，一首歌一律按放满算。
- 只有一个歌单、一台 iPhone、16 首歌，没覆盖手动切歌、随机播放、交叉淡入。

## 复现

`node --experimental-strip-types --import ./src/lib/testing/register-alias.mjs scripts/listening-replay.mts` 打印新算法各间隔与生产窗口的数字。`src/lib/pulse-listening-replay.test.mts` 守住每分钟一轮的下限。
