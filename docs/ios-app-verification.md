## 实现范围

- Now Playing 展开页：限制封面尺寸，采用曲目信息、进度、Listen Along 和底部操作布局；背景取封面模糊配色，歌词可切换、自动跟随当前行；支持横屏与动态字体。
- `SystemMusic.listenAlong`：通过 MediaPlayer 把当前曲库 ID、当前进度、后续队列与单曲循环交给系统音乐 App；补齐 Apple Music 权限说明、缺曲库 ID、授权失败、缺音乐 App 与模拟器的提示。
- Library 使用原生 List 的左滑操作与 ShareLink，看片详情使用原生导航；Pulse 使用 Swift Charts 手势选择并保留时刻明细。
- 上报设置只允许 HTTPS 地址；模拟器测试与确定性歌词代理可以从 README 的命令复跑。
