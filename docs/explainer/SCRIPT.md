# lyjw.me 运行原理 · 分镜与旁白（v2）

> 类型：reference

新版 `/explainer`（`v2/`，全篇 2D）的分镜。三样东西以这里为唯一出处：**章节表**（每章小节数，`v2/plan.js` 抄这里）、**每一段的画面要点**、**中英旁白原文**（各章文件顶部的 `I18N.add` 抄这里）。事实出处在 [FACTS.md](FACTS.md)，画法、母题与调色板在 [TREATMENT.md](TREATMENT.md)，写章的契约在 [v2/CONVENTIONS.md](v2/CONVENTIONS.md)。

- **节拍**：108 BPM，4/4，一小节 20/9 秒（约 2.22 秒）。小节从 0 数，章内写「小节:拍」，拍也从 0 数：5:2 是第 5 小节的第三拍；表里「2–5」指第 2 小节开头到第 5 小节开头。
- **主角**：Mac 上的一次换歌（`mac · appleMusic`）。片子跟着这封信封，从 Mac 一路走到访客屏幕上那张「正在听」卡片翻面。
- **旁白**：每句两行，逐字亮起，排在图版里，不是字幕，也不是 Clawd 的气泡。按 60 px、`maxW` 1040 排：中文每行不超过 17 字，英文每行不超过 36 个字符（Geist 60 px 平均约 28 px 一个字符），再长会被缩到 56 px 以下。改旁白先改这里，再改章节文件。
- **Clawd**：片子的脸，每章都有戏，说的话放在气泡里，不算旁白：开场的终端和第 00 章主页上的客串、第 01 章结尾骑上信封、第 02 章骑着火花进门、第 03 章在黑白胶片里上了一笔橙、从账房桌角冒出来说「记一笔就好」、第 04 章戴鸭舌帽的报童、第 05 章戴耳机的报务员、第 06 章从地层冒出来、第 07 章 Opus 卡上戴安全帽的 Architect、第 08 章整章（一只 Clawd 就是一个 Claude）、第 09 章戴制帽的列车员 Clawd 举牌吹哨发车、拿放大镜看两个域名换好的小 Clawd、第 10 章骑着信封一站站换画风（等距方块、构成主义剪影、橡皮管、网点、剪纸、晒图零件），片尾十种画风的十只 Clawd 站在十条竖幕上谢幕。
- **不上画面**：见 [v2/CONVENTIONS.md](v2/CONVENTIONS.md)「事实」一节。编码用量只讲到「Mac、云端、容器代报的 Cursor 账号各报原始事实，站点侧合并；Pulse 上有一条 token 处理量（5 分钟平均）」，不点存储键和模块名；不说「生成速度」，也不说它是此刻的精确值（FACTS §1「编码用量」）。

## 01 野外观测站（29 小节）

事实：FACTS §1。下表按 `ch01.js` 和 `v2/music/ch01.js` 的现状写。画面标题「野外观测站 / Field stations」，副标 `reporters · collector Worker`。整章是一座粉彩漂浮小岛的立体微缩，用 three.js 渲染（`ch01-models.js` 搭模型、`ch01-world.js` 渲染）：上报器和钟楼都是圆角方块搭的小房子，暖色主光打出柔和的投影，冷色天光补暗面，一道轮廓光勾边，落地处压一圈假的环境光遮蔽；远处带一点雾和移轴景深，像拍桌上的模型。信封是一只纸盒，沿岛上的导轨滑；结尾的 Clawd 是体素方块拼的。镜头是一台 26° 小视角的透视相机，站与站之间都是同一种走法：沿弧线推拉，中途升高、退远一点再落下，方位只在几站之间小幅偏转；每个机位停住时慢推 1.5%，标注在机位到位后才亮、起甩前收；每次起甩配一口轻风（`whoosh` 的 `tube: "whip"`，起甩那一刻起，按画面滑动的方向扫）。字、牌子和标注都画在模型上面的 2D 层里，锚点从立体模型投影过来，不被模型挡；要读的字放在奶油色圆角牌子上，字体是 Fredoka 与站酷快乐体（日文歌名用 Zen Maru Gothic），端点与字段用 Geist Mono。
