# 鼠标停在主题切换按钮上时显示当前模式

## 想要什么
## 目标
页头右上角的主题切换按钮加一个原生 `title` 提示，显示当前选中的主题模式。改动越小越好。

## 行为
- 在 `src/components/theme-toggle.tsx` 的 `ThemeToggle` 里，给 `<button>` 加 `title={`Theme: ${theme}`}`。`theme` 直接用已有的 `useTheme()` 返回值，取值为 `light` / `dark` / `system`（来自 `THEME_CHOICES`）。
- 提示文字固定为英文格式 `Theme: light`、`Theme: dark`、`Theme: system`，跟站内界面文案一律用英文的规则一致。
- 点击切换后 `theme` 会变，提示文字随之更新。
- 保留现有的 `aria-label`、样式、图标和切换逻辑，都不改。
- 服务端渲染时 `useTheme` 的服务端快照是 `system`，水合后由 `useSyncExternalStore` 换成客户端实际选择，所以不会出现水合不匹配，也不需要额外处理。
- 不加注释，不新增测试（低影响 UI 改动）。

## 验收标准
- [ ] 鼠标悬停在页头主题按钮上，浏览器原生提示显示当前模式，例如默认时显示 "Theme: system"
- [ ] 点一下按钮切换到下一个模式后再悬停，提示依次变为 "Theme: light"、"Theme: dark"、"Theme: system"，和实际模式一致
- [ ] 已经选了 dark 的情况下刷新页面，悬停时显示 "Theme: dark"，控制台没有水合相关的报错
- [ ] 按钮的外观、图标、点击切换效果和读屏标签都和改动前一样
