# 页头 Claude Code 像素小人悬停时提示“Using Claude Code”

## 想要什么
## 目标

页头正中的“当前前台应用”标记在识别为 Claude Code 时，会显示一个会动的像素小人。鼠标悬停在这个小人上时，浏览器原生提示（`title`）显示文字 `Using Claude Code`。

## 现状

- `src/components/live/live-desk-card.tsx` 的 `HeaderDesktop`：外层容器上已有 `title={hoverText}`，悬停整块标记时显示 `Claude Code` 或 `Claude Code · <窗口标题>`。
- 应用图标渲染在一个 `motion.span` 里（`activeOverride ? ( <motion.span …>{activeOverride.renderIcon(...)}</motion.span> )` 这一分支）。

## 改动（越小越好）

- 只改 `src/components/live/live-desk-card.tsx`。
- 在上述包裹覆盖图标的 `motion.span` 上加 `title`，仅当 `activeOverride.key === "claude-code"` 时为 `"Using Claude Code"`，其他情况为 `undefined`。
- 内层元素的 `title` 会覆盖外层容器的提示，所以只有悬停小人时显示新文字。悬停文字或窗口标题时，仍显示原来的 `hoverText`。
- 不动 `ClaudeCodeMascot` 组件本身（它是 `aria-hidden` 的装饰 SVG），也不改其他应用（Cursor、Ghostty、Antigravity、普通图标）的行为。不改外层的 `aria-label`。
- 不加注释，不新增测试。这是低风险的单行 UI 改动。

## 边界

- 离线、锁屏、空闲时不渲染该分支，所以不会出现这个提示。
- 手机上没有悬停，行为与现在一样。深色模式无影响。

## 验收标准
- [ ] 当页头显示 Claude Code 像素小人时，鼠标悬停在小人上，浏览器原生提示显示“Using Claude Code”。
- [ ] 鼠标悬停在同一标记的“Claude Code”字样或窗口标题上时，提示仍为原来的应用名（及窗口标题）。
- [ ] 前台为其他应用（如 Cursor、Ghostty 或普通应用图标）时，悬停图标不会出现“Using Claude Code”。
- [ ] 改动只涉及 src/components/live/live-desk-card.tsx，且 pnpm typecheck 与该文件的 eslint 检查通过。
